# Termux-Zsh vNext Command Suite Reference

The `Termux-zsh` framework includes a suite of management CLI tools:

| Command | Usage | Description |
| :--- | :--- | :--- |
| `termux-settings` | `termux-settings` | Interactive terminal UI settings dashboard. |
| `termux-doctor` | `termux-doctor [--fix]` | Runs 12 automated diagnostics & auto-repairs. |
| `termux-theme` | `termux-theme [list\|set <name>\|current]` | Color scheme manager. |
| `termux-font` | `termux-font [list\|set <1-12>\|restore]` | Nerd Font manager. |
| `termux-plugin` | `termux-plugin [list\|install <url>\|update\|remove <name>]` | Zsh plugin manager. |
| `termux-packages` | `termux-packages [list\|install <profile>\|tools]` | Package profile installer assistant. |
| `termux-backup` | `termux-backup [list\|create <label>\|restore\|clean]` | Backup and restore manager. |
