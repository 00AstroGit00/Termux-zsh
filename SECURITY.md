# Security Policy

## Supported Versions

The following versions of `Termux-zsh` are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 7.0.x   | :white_check_mark: |
| 6.0.x   | :white_check_mark: |
| < 6.0   | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in `Termux-zsh`, please report it by opening a confidential security advisory on GitHub or contacting the maintainers directly.

We appreciate responsible disclosure and will investigate all reports promptly.
